# 01 · 项目概览

## 项目解决什么问题

手上有多个 Tavily API key(如几十个免费账号,每个 1000 credits/月),希望:

1. 对外只暴露**一个 MCP 服务地址**,任何 MCP 客户端(Claude Code / Cursor 等)都能用
2. 多个 key **自动轮流使用**,单 key 限流/耗尽时无感切换,容量叠加
3. 部署在公网,因此必须有**鉴权**(签发给使用者的访问 Token)、**限流配额**(防滥用)和**管理控制台**(看用量、管 key、发 Token)

## 核心功能

| 功能 | 说明 |
|---|---|
| Key 池调度 | 轮询均摊;429 冷却换 key、432/433 标记耗尽并月初恢复、401 禁用、5xx 换 key 重试、4xx 透传;付费 key(>1000 credits)按 key 配额,校准自动回填真实限额 |
| MCP 工具 | `tavily_search` / `tavily_extract` / `tavily_crawl` / `tavily_map` / `tavily_research` / `get_my_usage`,crawl/map/research 需"完整"等级 Token(research 为异步深度研究,提交后轮询同 key 至完成) |
| 双种鉴权 | `https://域名/mcp?token=tpm_xxx`(URL 直填)或 `Authorization: Bearer tpm_xxx` |
| Token 治理 | 签发(明文一次性显示 + 加密存储可再导出)、吊销即时生效、RPM / 日配额 / 月 Credits 三层限额、**按 Token 工具白名单**(allowed_tools) |
| 告警通知 | key 禁用 / 全池不可用 / 可用数与剩余配额阈值告警,推送飞书/企微/钉钉(可签名)/通用 Webhook/邮件(SMTP,支持授权码),事件冷却去重 |
| 可观测性 | 请求日志含查询内容与来源 IP;`/metrics` Prometheus 指标(请求/credits 计数、池健康 gauge) |
| 控制台 | 概览趋势、Key 卡片(含零成本「测试连接」与「全量校准」)、Token 管理(一键导出 MCP 地址)、请求日志(含查询词)、网站设置(公告/站名/图标/改密码/告警配置) |
| 运维自动化 | 配额每 6h 校准(账户级回退)、日志 30 天滚动清理、数据库自动迁移 |

## 技术栈

| 层 | 选型 |
|---|---|
| MCP 服务 | Python 3.12+ / **FastMCP 3.4**(锁定 `>=3.4,<4`,v4 尚在 beta) |
| Web 容器 | Starlette(FastMCP `http_app()` 提供)+ uvicorn |
| HTTP 客户端 | httpx(异步,上游 Tavily) |
| 存储 | SQLite(aiosqlite,WAL 模式,单连接);监控导出用 prometheus-client |
| 加密 | cryptography(Fernet 加密 Token 明文以便导出)、hashlib PBKDF2(管理密码)、SHA-256(Token 哈希) |
| 前端 | React 19 + TypeScript + Vite + Tailwind v4 + shadcn/ui(radix/nova 预设)+ recharts + react-router(HashRouter) |
| 部署 | Docker 多阶段构建;宿主 Nginx 反代(自有证书服务);GitHub Actions → 腾讯云 TCR → 服务器 compose 拉起 |

## 仓库结构

```
tavily-pool-mcp/
├─ app/                    # 后端(Python,全部业务逻辑)
│  ├─ main.py              # 入口:ASGI 组装、最外层中间件、静态托管、/metrics
│  ├─ config.py            # 环境变量 → Config
│  ├─ db.py                # SQLite 封装、建表、迁移、settings KV
│  ├─ pool.py              # KeyPool 调度器(核心状态机,可挂 Alerter)
│  ├─ tavily.py            # Tavily 上游客户端 + /usage 解析
│  ├─ mcp_server.py        # FastMCP:鉴权/限流中间件/池化执行器/工具
│  ├─ admin_api.py         # 管理 REST API + 会话 + 设置
│  ├─ alerts.py            # 告警通知(队列 + 去重;Webhook×4 渠道 + 邮件 SMTP)
│  ├─ metrics.py           # Prometheus 指标定义与 /metrics 响应
│  ├─ tasks.py             # 后台任务(配额校准/日志清理)
│  └─ state.py             # AppState 全局单例
├─ dashboard/              # 前端(React SPA,构建产物进镜像)
│  ├─ src/pages/           # Login/Overview/Keys/Tokens/Logs/Settings
│  ├─ src/components/      # Layout(侧边栏+公告横幅)+ shadcn ui 组件
│  └─ src/api.ts           # 类型化 API 客户端
├─ tests/                  # pytest:单测 + 端到端集成(53 用例)
├─ deploy/docker-compose.yml  # 生产部署版(拉腾讯云镜像,绑 127.0.0.1)
├─ .github/workflows/deploy.yml  # CI:构建推镜像 → scp compose → SSH 部署
├─ Dockerfile              # 多阶段:node 构建前端 → python:3.12-slim 运行
├─ docker-compose.yml      # 本地构建版(绑 ${APP_PORT:-8000})
└─ docs/wiki/              # 本文档
```

## 代码规模

- 后端约 3,000 行 Python(11 个业务模块),单文件最大 `mcp_server.py`(919 行)与 `admin_api.py`(808 行);告警模块 `alerts.py` 341 行
- 前端 6 个页面 + Layout,构建产物约 837 KB(gzip 250 KB,含 recharts)
- 测试 7 个文件、56 个用例,无网络依赖(上游用可脚本化的 FakeTavily)
